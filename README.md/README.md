# Sitio Café Aroma

Proyecto web estático desarrollado para el examen práctico de Git y control de versiones. El sitio consta de una estructura de varias páginas (Inicio, Menú y Contacto) diseñadas con HTML5, CSS3 y JavaScript básico.

## Estructura del Proyecto
- `index.html`: Página principal de bienvenida.
- `menu.html`: Catálogo de productos y precios.
- `contacto.html`: Formulario de contacto para clientes.
- `css/styles.css`: Estilos generales y diseño adaptable del sitio.
- `js/main.js`: Lógica principal en JavaScript.

## Ramas de Características Implementadas
- `feature/navbar`: Creación y estilización de la barra de navegación compartida.
- `feature/menu-productos`: Sección detallada de productos y precios del menú.
- `feature/formulario-contacto`: Implementación y diseño del formulario de contacto.
